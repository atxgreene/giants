# Marketing key art

Promotional key art for **THE WATCHERS: FALL OF THE GIANTS** — the Appointed
Witness with the Flaming Sword and the glowing Archive, before the Eye of
Revelation and the half-risen giants of the Desert of Azazel.

The master files live under `docs/media/` (so GitHub Pages can serve them and
the landing page / link previews can reference them). They are intentionally
**not** duplicated here.

| File (`docs/media/`) | Size | Aspect | Use |
|---|---|---|---|
| `keyart-wide.png` | 1672×941 | 16:9 | Open Graph / Twitter card, store/itch cover, widescreen banner |
| `keyart-square.png` | 1254×1254 | 1:1 | social posts, square thumbnails |
| `keyart-portrait.png` | 1122×1402 | 4:5 | poster, Instagram feed |
| `keyart-mobile.png` | 941×1672 | 9:16 | mobile splash, stories/reels |

Notes:
- These posters have the title and a "Play Free" call-to-action baked in, so
  they are for marketing/sharing — **not** used as the in-game main-menu
  background (which renders its own title text over the concept art).
- Source PNGs are ~3.4 MB each. Before a wide marketing push, run them through
  an optimizer (`pngquant`/`cwebp`) and consider `.webp` variants for the web;
  no lossless image tooling was available in the environment that added them.
